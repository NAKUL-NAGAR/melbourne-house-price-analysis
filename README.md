# Melbourne House Price Analysis

## 📊 Project Overview

This project analyzes Melbourne house prices using Python and Power BI.

The project covers data cleaning, data preprocessing, feature engineering, exploratory analysis, and interactive dashboard creation.

## 🛠️ Tools Used

* Python
* Pandas
* NumPy
* Power BI
* Power Query
* DAX
* GitHub

## 📈 Power BI Dashboard

The Power BI dashboard contains three pages.

### 1. Housing Overview

The dashboard contains:

* Total Properties
* Average Price
* Median Price
* Maximum Price
* Average Rooms
* Average Price by Region
* Property Type Distribution
* Average Price by Rooms
* Price Trend

### 2. Price Analysis

This page contains:

* Average Price by Suburb
* Average Price by Property Type
* Price Category Analysis
* Price per Room Analysis

### 3. Location Analysis

This page contains:

* Distance vs Price
* Properties by Region
* Average Price by Council Area

## 🎯 Project Objective

The objective of this project is to understand Melbourne's housing market through property prices, property types, number of rooms, regions, suburbs, and distance from the city.
